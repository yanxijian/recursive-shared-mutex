# Benchmark results: MSVC

- Toolchain: MSVC (Microsoft (R) C/C++ Optimizing Compiler Version 19.51.36248 for x64)
- Generated by `benchmarks/run_bench.ps1`: medians of 5 run(s), 3s per run
- Commit: `v0.4.0` (measured at cfe6ef5; the library code is identical to the tag)
- Runner: local
- Host hw_concurrency: 32
- Backend: std::shared_mutex, 8 B
- Run-to-run spread over 5 run(s): median 48%, worst S1 245%
- Dataset: 1,048,576 x uint32 (~4 MiB); nested reenter depth 3; read window 24 / write window 12

> Absolute numbers are specific to the machine; the meaningful column is the speedup vs `recursive_mutex` measured in the same run.
